# Security policy

TOOLS-GITHUB-ACTIONS-MONITOR-WATCH is at its first steps and has no code yet. It is planned as a minimal client that only reads from the monitor of its user, so please report anything in this repository that could expose a secret, a token or a key, or any statement here that would make a reader trust something that does not exist yet.

## Reporting a problem

Please report it privately to **electrohobby3d@gmail.com**, with what you found and where. Do not open a public issue for it. You will get an answer as soon as possible; this is a one-person project.

Only the latest version is supported.

## What this repository promises

* No secret belongs here: no key, no token, no push-service file and no signing key.
* Nothing is claimed to work that has not been run; today there is no application code at all.
